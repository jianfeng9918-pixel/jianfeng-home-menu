# 剑锋家菜单

欢迎来家一起吃好吃的！

无需登录、不显示价格的家庭点菜网页。三道招牌菜 → 招牌套餐 → 家常菜单，选好菜后统一填写口味与忌口，复制菜单发到微信。

## 修改方式

- `index.html`：网页结构与门头。
- `styles.css`：手机、电脑布局和样式。
- `menu.js`：99 道菜、分类、标签和招牌套餐。修改时保持菜品 ID 稳定。
- `images.js` 与 `assets/`：菜图配置和 102 张本地图片。
- `app.js`：搜索、选菜、数量、统一口味忌口、浏览器本地保存和复制。
- `图片来源与许可.json`：图片来源和许可记录。图片权利独立于网页代码，unknown 不代表开放许可。

这是无需构建的静态网页。GitHub Pages 使用 main 分支根目录，修改并推送后自动更新。

选择仅保存在当前浏览器，复制后由本人粘贴发送，不向服务端提交点单数据。复制失败时提供完整文本供手动复制。

## 验证情况

源网页已检查手机、电脑布局和选菜复制流程。GitHub Pages 发布结果、普通网络访问和微信内实际访问应分别确认；不能用电脑浏览器或更换 User-Agent 代替微信真机验证。
